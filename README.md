# 🐾 Canlı Atlası
### Dijital Biyoçeşitlilik ve Yaban Hayatı Keşif Platformu

**Canlı Atlası**, dünyanın dört bir yanındaki hayvan türlerini keşfetmeyi, biyolojik çeşitliliği incelemeyi ve açık bilimsel verileri etkileşimli bir deneyime dönüştürmeyi amaçlayan dijital bir biyoçeşitlilik platformudur.

Kullanıcılar hayvan türlerini arayabilir, taksonomik gruplar arasında gezinebilir, türlerin coğrafi dağılımlarını harita üzerinde inceleyebilir ve bilimsel veriler üzerinden karşılaştırmalı analizler yapabilir.

Canlı Atlası, biyolojik çeşitlilik verilerini yalnızca listeleyen bir katalog değil; keşif, görselleştirme ve veri analizini tek bir platformda buluşturan genişletilebilir bir dijital bilgi sistemidir.

---

## 🌍 Proje Hakkında

Biyolojik çeşitlilik verileri farklı bilimsel veri tabanlarında, araştırma platformlarında ve kurumsal kaynaklarda dağınık biçimde bulunmaktadır. Bu verilere erişmek, farklı türleri karşılaştırmak ve coğrafi dağılımlarını anlamlandırmak her kullanıcı için kolay değildir.

Canlı Atlası bu soruna çözüm sunmak amacıyla geliştirilmiştir.

Platform, açık biyolojik çeşitlilik verilerinden yararlanarak hayvan türlerini keşfetmeyi, türler arasındaki taksonomik ilişkileri incelemeyi ve gözlem kayıtlarını görsel analizlerle değerlendirmeyi sağlar.

## ✨ Öne Çıkan Özellikler

### 1. Dinamik Tür Keşfi
- Hayvan isimleri üzerinden arama yapabilme.
- Farklı taksonomik gruplar arasında gezinebilme.
- Türleri üst gruplarından alt gruplarına doğru keşfedebilme.
- Bilimsel ad ve Türkçe ortak ad bilgilerini görüntüleyebilme.
- Tür detaylarına erişebilme.
- Sayfalama yoluyla geniş tür kataloglarını inceleyebilme.

### 2. Küresel Biyoçeşitlilik Haritası
- Türlerin gözlem kayıtlarını harita üzerinde görüntüleme.
- Coğrafi dağılımları inceleme.
- Gözlem noktalarını etkileşimli harita üzerinde değerlendirme.
- Bölgesel biyoçeşitlilik hakkında fikir edinme.

### 3. Tür Analizleri
- Türlere ait bilimsel bilgileri görüntüleme.
- Gözlem kayıtlarını inceleme.
- Türkiye ve küresel veri kapsamlarını değerlendirme.
- Türlerin biyolojik ve taksonomik özelliklerini araştırma.

### 4. Karşılaştırmalı Tür Analizi
- İki farklı türü karşılaştırabilme.
- Türlerin özelliklerini birlikte inceleyebilme.
- Biyolojik çeşitlilik hakkında karşılaştırmalı değerlendirmeler yapabilme.

### 5. Zamansal ve Bölgesel Analiz
- Yıllara göre gözlem kayıtlarını inceleme.
- Bölgesel dağılım verilerini değerlendirme.
- Biyoçeşitlilik verilerini grafiklerle görselleştirme.

### 6. Koruma Durumu Bilgileri
- IUCN koruma kategorilerini inceleme.
- Tehdit altındaki türler hakkında bilgi edinme.
- Türlerin koruma durumlarını değerlendirme.

### 7. Türkiye ve Global Veri Görünümü
- Türkiye ve dünya genelindeki gözlem verilerini ayrı ayrı inceleme.
- Gözlem sayıları ile biyolojik tür kataloğunu birbirinden ayırma.
- Türkiye'de gözlemi bulunmayan türleri de küresel tür kataloğunda görüntüleyebilme.

**Önemli:** Bir türün Türkiye'de gözlem kaydının bulunmaması, o türün katalogdan kaldırılması anlamına gelmez. Böylece yerel gözlem verileri ile küresel biyolojik çeşitlilik bilgileri birbirine karıştırılmaz.

## 🧬 Veri Kaynakları

Canlı Atlası, açık bilimsel veri kaynaklarından yararlanacak şekilde geliştirilmiştir.

| Veri kaynağı | Kullanım alanı |
|---|---|
| GBIF | Tür taksonomisi, biyolojik çeşitlilik ve gözlem kayıtları |
| iNaturalist | Tür eşleştirme, ortak adlar ve görsel bilgileri |
| IUCN | Türlerin koruma durumları |
| Wikimedia Commons / Wikipedia | Uygun olduğunda görsel ve tamamlayıcı bilgi kaynakları |

Veri kaynaklarının güncelliği, erişilebilirliği ve kullanım koşulları ilgili sağlayıcıların hizmetlerine bağlıdır. Kaynakların lisans ve atıf koşulları ayrıca dikkate alınmalıdır.

## 🚀 Kurulum

### Gereksinimler
- Node.js
- npm
- Git

### Projeyi klonlama

```bash
git clone REPOSITORY_URL
cd canli-atlasi
```

### Bağımlılıkları yükleme

```bash
npm install
```

### Geliştirme sunucusunu başlatma

```bash
npm run dev
```

> Not: Sunucu ve API yapılandırması proje dağıtım ayarlarına göre ayrıca yapılmalıdır. Gerekli ortam değişkenleri ve yapılandırma bilgileri dağıtım paketinde belirtilmelidir.

### Üretim derlemesi

```bash
npm run build
```

## 📌 Projenin Öne Çıkan Değeri

Canlı Atlası'nın temel farkı, biyolojik çeşitlilik verilerini tek bir keşif deneyiminde birleştirmesidir.

- Yalnızca belirli hayvanlarla sınırlı olmayan dinamik taksonomik keşif yaklaşımı.
- Tür kataloğu ile gözlem kayıtlarının birbirinden ayrılması.
- Türkiye ve küresel veri kapsamının birlikte değerlendirilebilmesi.
- Harita, analiz, karşılaştırma ve keşif modüllerinin aynı platformda bulunması.
- Açık veri kaynaklarıyla genişletilebilir altyapı.
- Eğitim, araştırma ve kurumsal kullanım senaryolarına uyarlanabilir yapı.
